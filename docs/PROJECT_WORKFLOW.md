# Project Workflow

Use GitHub Issues for tasks, Milestones for phases, and PRs for review.

## Parallel work
Assign one owner per issue. Agree on scope, interfaces, and expected files before starting. Avoid simultaneous edits to shared files. Early DB/API contracts should be agreed before parallel feature work.

## Suggested workstreams
Backend/API; Database/migrations; Frontend; SDK/evaluation; Testing/docs.
